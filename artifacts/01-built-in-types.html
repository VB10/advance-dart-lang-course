Girdicamera null → sonra hazır · 'Kadıköy'

Olumsuz camera!..moveTo(place)..showPin(place)
⚠
Harita ekranı çöktü
Null check operator used on a null value

Erken dokunuşta TypeError.

Olumlu camera?..moveTo(place)..showPin(place)
Harita yükleniyor…◎

Neden: ?.. (null-aware cascade) alıcı null ise zincirin tamamını atlar; ilk adımda bir kez yazılır, sonraki ..'lar da korunur. ! "burada null olamaz" sözüdür; geç gelen kontrolcülerde (harita, kamera, video, WebView) bu söz tutmaz.

Üret
